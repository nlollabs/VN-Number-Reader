# Vietnamese Number Pad

A simple one-file webpage for learning to say the numbers 0–9 in Vietnamese.

Click a number (or type it on your keyboard or numpad) and the page speaks it aloud in Vietnamese, showing the Vietnamese word and a rough English phonetic spelling.

## Features

- Type several digits quickly and they are read together as one natural phrase
- A timer bar shows the 1-second wait before speech starts, then fills green as the audio is prepared
- Numbers pressed while it is speaking are queued and spoken next, never overlapping
- Prefers a male Vietnamese voice when the browser has one
- Works on mobile as well as desktop: tap the numbers on a phone or tablet
- No install, no dependencies: just open `vietnamese-numbers.html`

## Notes

Speech uses the browser's built-in voices, so a Vietnamese voice must be available. Microsoft Edge includes one; in other browsers you may need to install the Vietnamese speech pack in your system settings.

The phonetic spellings are approximations and do not show tones.
